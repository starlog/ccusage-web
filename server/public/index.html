클라이언트 설정 방법

각 컴퓨터에서 Claude Code 사용량을 이 서버로 보내는 방법입니다.

입력하면 아래 명령어에 채워집니다. 사용자 ID는 영문, 숫자와 . _ % + @ -만 쓸 수 있고, 한글 이름은 이름 칸에 입력하세요.

  1. 준비

    Claude Code를 사용하는 컴퓨터에 Python 3.9 이상과 Node.js(npx)가 있으면 됩니다. 추가로 설치할 패키지는 없습니다. Windows에서는 ./ccusage_report.py 대신 python ccusage_report.py로 실행하세요.

  2. 스크립트 받기

    소스는 github.com/starlog/ccusage-web에서도 볼 수 있습니다.

  3. 최초 1회 설정

    사용자 ID, 이름, 서버 주소를 이 컴퓨터에 저장합니다 (~/.config/cc-usage/config.json). 사용하는 컴퓨터마다 한 번씩 실행하세요.

    이 서버는 업로드 토큰이 필요합니다. 관리자에게 받은 토큰으로 YOUR_TOKEN을 바꾸세요.

    지금 localhost로 접속 중입니다. 다른 컴퓨터에서는 localhost 대신 이 서버의 주소를 넣으세요.

  4. 사용량 보내기

    성공하면 [upload] … -> 서버 주소: … tokens 메시지가 나옵니다. 대시보드를 새로고침하면 반영됩니다. 같은 기간을 다시 보내도 중복되지 않습니다.

  5. 설정 확인

    저장된 사용자 ID, 이름, 머신 ID, 서버 주소를 보여줍니다. 이름만 바꾸려면 --name 새이름 --save-config를 실행하세요.

  6. 자동으로 보내기 (선택, macOS·Linux)

    crontab -e에 아래 줄을 추가하면 매일 저녁 7시에 최근 7일을 보냅니다. cron은 PATH가 짧으므로 <node 폴더>를 dirname "$(which node)" 결과로 바꾸세요.

서버로 보내는 정보

사용자 ID, 이름, 머신 ID(OS 식별자의 해시), 호스트 이름, 그리고 기간 합계와 날짜별 토큰 수(입력·출력·캐시 생성·캐시 읽기)와 세션 수만 보냅니다. 비용, 프로젝트, 모델, 대화 내용은 보내지 않으며, 자세한 보고서는 내 컴퓨터의 reports/ 폴더에만 남습니다.
